# YouTube Engagement & Performance Dashboard (Looker Studio)

This project presents an interactive YouTube analytics dashboard built using Google Looker Studio to analyze channel performance and engagement trends.

## Overview
The dashboard tracks key performance indicators and compares metrics for the **last 28 days vs the previous 28 days** to highlight growth, decline, and user engagement patterns.

## Dashboard Preview
![YouTube Dashboard](YouTube_Analytics (2).jpg)

## Key Metrics
- Views  
- Watch Time  
- Video Likes Added & Removed  
- Video Dislikes Added & Removed  
- Video Comments Added  
- User Comments Added  
- User Subscriptions Added & Removed  

## Features
- KPI scorecards with period-over-period comparison  
- Interactive date filter  
- Geo-map visualization of audience distribution  
- Clean and professional dashboard layout for business insights  

## Tools Used
- Google Looker Studio  
- Google Sample YouTube Analytics Dataset  

## Project Purpose
The goal of this project was to practice dashboard design, KPI tracking, and time-based performance analysis using real-world structured datasets.
